# Feedback - BBone to Bones

This file collects user feedback from all channels: GitHub issues, Blender Extensions reviews, forum threads, and private messages. One entry per item, newest first. Paste verbatim, do not paraphrase. The triage step works on the original words.

---

## How to log an entry

```
### F-### [channel] [category] - short title
- Date:
- Source: (exact URL for web sources, or PM / email)
- Verbatim quote: (what the user actually wrote)
- Verdict: (filled during triage, not while importing)
```

Categories: `bug`, `feature`, `question`, `duplicate`, `out-of-scope`.

## Triage rules

- Every entry above gets one verdict during the next triage pass: `accepted`, `rejected`, or `needs-info`.
- A `bug` verdict requires a confirmed reproduction attempt before it reaches the roadmap.
- A `feature` verdict must state the user case in one line, not just the requested mechanism.
- Resolved entries move to the "Resolved" section below with the release that closed them, and stay there as history.
